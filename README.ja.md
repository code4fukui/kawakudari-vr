# kawakudari-vr

プレイヤーが下方向にスクロールする環境で障害物を避けるシンプルなVRゲームです。「kawakudari」という名前は、日本語の「川下り」を意味します。

## ゲームプレイ

ライブデモはこちら: **[https://fukuno.jig.jp/app/kawakudari-vr/](https://fukuno.jig.jp/app/kawakudari-vr/)**

この一人称視点のゲームでは、白いブロックのような障害物が浮かぶ暗い空間を一定の速度で前進します。空間は左右（水平方向）にループしているため、画面の端から反対側へとシームレスに移動して安全なルートを探すことができます。

## 遊び方

**目的:** 障害物にぶつかることなく、コースの終点（距離520）まで到達すること。

**操作方法:**
- **デスクトップ:** 左右の矢印キーで横移動します。
- **VR:** 頭を動かして操作します。

障害物に衝突すると画面が赤くなり、ゲームオーバーになります。終点に到達すると画面が白くなり、「CLEAR!」というメッセージが表示されます。

## 特徴
- [A-Frame](https://aframe.io/) を使用した、軽量なブラウザベースのVR体験。
- ランダムに配置された100個の障害物による、やりごたえのあるコース。
- 一定速度での前進によるスピード感。
- 左右に無限にループする（ラップアラウンド）空間での移動。
- ビルド不要、単一のHTMLファイルのみで動作。

## ローカルでの実行
1. このリポジトリをクローンまたはダウンロードします。
2. 最新のウェブブラウザで `index.html` ファイルを直接開きます。
